# شروع سریع نسخهٔ Go

برای دوربین و میکروفن به **macOS 14 یا جدیدتر** نیاز دارید. برای ساخت برنامه از سورس، Go 1.26 یا جدیدتر و Command Line Tools اپل را نصب کنید. در پوشهٔ پروژه اجرا کنید.

```sh
./build.sh
./bin/glyph-call
```

اگر بستهٔ آمادهٔ macOS دارید، می‌توانید آن را باز کنید و `bash Start.command` بزنید.

۲. نفر اول گزینهٔ **۱** را بزند و فقط حالت تصویر و صدا را انتخاب کند.
۳. کد را خصوصی برای نفر دوم بفرستد. نفر دوم گزینهٔ **۲** را بزند و کد را وارد کند.
۴. همهٔ گروه‌های کد امنیتی را مقایسه کنید؛ فقط در صورت برابری هر دو `yes` بنویسید. بعد دستگاه‌ها روشن می‌شوند. هدفون بزنید. `Ctrl+C` تماس را می‌بندد.

تصویر: **hidden** فقط ASCII کم‌جزئیات؛ **fun** ASCII Art یا Unicode رنگی؛ **graphic** تصویر واقعی در Ghostty/Kitty/iTerm2. اگر ترمینال قابلیتی را نداشته باشد، نزدیک‌ترین حالت قابل اجرا خودکار انتخاب می‌شود؛ مخفی هرگز به تصویر واضح‌تر تبدیل نمی‌شود.

منو سه صدای **واقعی، رباتی و ۸بیت** دارد. سبک فان و کیفیت صدا خودکار انتخاب می‌شوند؛ پیش‌فرض فان و صدای واقعی با سقف ۲۴ کیلوهرتز است. تنظیم هاست مبناست؛ کلاینت خودکار آن را دریافت می‌کند. گزینه‌های تخصصی در خط فرمان باقی‌اند.

```sh
./bin/glyph-call host --mode hidden --voice robot
./bin/glyph-call host --mode fun --voice 8bit
./bin/glyph-call host --mode graphic --voice real
```

نفر دوم فقط:

```sh
./bin/glyph-call connect
```

پیش‌نمایش بدون دوربین، میکروفن و شبکه:

```sh
./bin/glyph-call preview --synthetic --mode fun --seconds 5
```

با دوربین:

```sh
./bin/glyph-call cameras
./bin/glyph-call preview --mode fun --camera 0
```

مجوز Camera/Microphone را برای ترمینال در تنظیمات macOS فعال کنید. حالت مخفی تضمین ناشناس‌ماندن نیست. اطلاعات شروع تماس از سرویس عمومی رمز‌شده عبور می‌کند؛ رسانه مستقیم و رمز‌شده است. بعضی NATها به رله نیاز دارند که هنوز پیاده نشده است.

اگر فقط سورس را دارید و باینری موجود نیست، `bash build.sh` به Go 1.26+ و ابزارهای ساخت اپل نیاز دارد. [راهنمای کامل انگلیسی](../README.md)
